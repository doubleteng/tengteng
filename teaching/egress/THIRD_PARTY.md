# Third-party components

- **LibreDWG Web 0.8.2** — MLightCAD and GNU LibreDWG contributors; GPL-3.0. Unmodified browser distribution from npm `@mlightcad/libredwg-web@0.8.2`. Wrapper source, binding sources, build scripts and GNU source are linked below. The app's GPL license text is LICENSE.txt.
  - https://github.com/mlightcad/libredwg-web
  - https://github.com/mlightcad/libredwg-web/tree/45a2a217f4916daddd7bd598c900d6c698d141b6
  - https://www.gnu.org/software/libredwg/
  - Reproduce the npm browser distribution using the package's `build:prepare`, `build:obj`, `build:wasm`, `copy` and `build` scripts. `package-lock.json` pins the distributed archive and integrity. Corresponding source details are recorded in SOURCE_VERSIONS.json.
- **rhino3dm 8.17.0** — Robert McNeel & Associates and contributors; MIT. License: vendor/rhino/LICENSE.txt. Source: https://github.com/mcneel/rhino3dm/tree/8.17.0
- **dxf-parser 1.1.2** — GDS Storefront Estimating and contributors; MIT. License: vendor/DXF-LICENSE.txt. Source: https://github.com/gdsestimating/dxf-parser ; bundled with esbuild 0.25.12.
- **PDF.js** — Mozilla Foundation; Apache-2.0. License: vendor/PDFJS-LICENSE.txt. Browser modules reuse the exact PDF.js assets already checked into this repository's structural-systems teaching lab. Source: https://github.com/mozilla/pdf.js
- DM Sans and IBM Plex Mono are requested from Google Fonts and fall back to system fonts.

The Rhino example is generated by this application's test setup. The native DWG test fixture is the LibreDWG `test/test-data/2000/Arc.dwg` sample; upstream attribution and license remain applicable. It is used only as a decoder regression fixture.

Complete corresponding LibreDWG and JavaScript binding source (including build scripts) for the pinned release is available at [this source archive](https://github.com/mlightcad/libredwg-web/archive/45a2a217f4916daddd7bd598c900d6c698d141b6.tar.gz). No changes have been made to its distributed WebAssembly.
