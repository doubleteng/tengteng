管理你的作品集。

在表单中更新文字、上传图片和简历。保存后，内容会写入你的 GitHub 仓库，网站自动更新。

01 · 首次使用

用 GitHub 登录

  1. 点击“进入管理后台”，选择 Sign in with GitHub，使用 doubleteng 账号。
  2. 首次使用时，按 Pages CMS 提示安装 GitHub App。选择 Only select repositories，只勾选 tengteng。
  3. 回到后台，选择 doubleteng / tengteng，分支选 main。左侧会出现中文内容菜单。

首次登录和授权需要你自己完成。无需购买服务器或创建数据库。

02 · 日常更新

填写 → 上传 → 发布

  1. 在“作品管理”中新建作品，填写名称、分类、年份和简介。
  2. 上传封面，编辑正文。在“图文内容区块”中添加相册，可一次上传多张图片并调整顺序。
  3. 准备好后打开“发布到网站”，点击保存。首页精选、分类目录与项目详情会自动同步。

通常需要几分钟完成发布。保存草稿时保持“发布到网站”关闭。

我想先保存，之后再发布

关闭“发布到网站”再保存即可。草稿不会出现在网站目录，也不会生成公开详情页。你可以在后台继续编辑和查看富文本排版；完整网页效果在发布构建完成后查看。仓库本身是公开的，因此草稿文件不是保密空间。

图片和文件怎样上传更方便？

在图片字段中直接上传，或从“图片素材”选择已有图片。建议图片最长边约 2000 像素、每张 2 MB 以内，使用 JPG 或 WebP。不同内容使用不同文件名；请勿删除仍被其他作品使用的图片。长视频推荐先上传到 YouTube／Vimeo，再粘贴链接。

保存后网站没有立刻变化

先确认分支为 main，且内容已开启发布。等待几分钟后刷新网站。仍未更新时，可查看 GitHub 的构建记录 ↗。绿色表示成功，黄色表示进行中，红色表示失败。

已有作品还有哪些内容需要补充？

在“作品管理”中搜索“待补充”或“原站没有”，查看“编辑备忘”。原站中的真实资料和图片已迁移；不确定的旧新闻保留为草稿，请核实后再发布。简历 PDF 尚未上传时，网站不会显示空的下载按钮。

我改错了，可以恢复吗？

每次保存都保存在 GitHub 的版本历史中。可打开对应文件的 History，查看并恢复之前的内容。撤下作品只需要关闭发布，不必删除；修改标题时保留文件名，避免改变新作品的网址。
