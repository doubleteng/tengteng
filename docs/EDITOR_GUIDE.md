# 作品集后台使用说明

后台入口：**https://teng-teng.org/admin/**

编辑器：**https://app.pagescms.org/doubleteng/tengteng/main**

内容保存位置：`doubleteng/tengteng` GitHub 仓库。

## 选择界面语言

登录后，展开左侧 **中文** 或 **English**，进入对应的教程和内容菜单。两套菜单编辑同一份项目、图片和资料，切换语言不会翻译或复制网站内容。图片与文件菜单共用。Pages CMS 自带的 Save、Settings 等系统按钮为英文。

切换前请保存正在编辑的内容。

## 第一次登录

1. 打开编辑器，选择 **Sign in with GitHub**，登录 doubleteng。
2. 如提示安装 Pages CMS GitHub App，选择 **Only select repositories**，仅选择 **tengteng**。
3. 回到 Pages CMS，选择仓库和 **main** 分支。
4. 登录后先打开左侧“使用教程”。其他菜单包括“作品管理、论文与出版物、新闻与动态、个人资料与简历、教学介绍与课程、艺术作品、网站文字与设置”。

首次 GitHub 登录和应用授权由网站所有者完成。之后直接打开后台即可。

## 新建作品

1. 打开“作品管理”，点击新增。
2. 填写名称、分类、年份和一句话简介。新作品的文件名由标题生成，建议使用简短英文文件名。创建后不要修改文件名，以保持网址稳定。
3. 上传封面，填写图片描述。
4. 编辑项目正文：建议包括**背景、目标、个人职责、方法、过程和成果**。
5. “图文内容区块”支持按顺序添加：文字、单图、批量相册、视频、引文、下载链接。
6. 补充团队、署名、机构、相关论文和奖项。没有的项目可留空，不会显示空标题。
7. 先保持“发布到网站”关闭并保存。确认准备好后，打开发布并再次保存。

保存一条作品，分类页、完整目录和详情页会一起更新。打开“显示在首页精选”即可进入首页；排序数字越小越靠前。

原有 34 个作品保留原网址；新作品自动使用 `/projects/文件名/`。已有记录中的 `permalink` 由系统保留，无需编辑。

## 上传图片和视频

- 可直接在封面、单图或相册中上传，也可以在“图片素材”中管理。
- 相册支持一次选择多张图片，并调整排列顺序。可选每行 1、2 或 3 张；手机会自动适配。
- 每张图片需要不同说明或署名时，使用多个“单张图片”区块。
- 建议最长边约 2000 像素、每张 2 MB 以内，使用 JPG 或 WebP。后台保存原上传文件，不会自动压缩后续上传。
- 相同内容可复用已有图片。不同图片使用不同文件名，避免覆盖；不要删除其他页面还在使用的素材。
- 视频推荐粘贴 YouTube 或 Vimeo 地址，也支持公开 MP4/WebM 文件链接。不建议把长视频放入 GitHub 仓库。

## 更新简历和个人资料

打开“个人资料与简历”，修改职位、机构、邮箱、简介或经历。列表顺序与网页一致。

在“上传简历 PDF”中上传文件；About 页面会自动出现 **Download CV**。替换文件后保存即可更新下载内容。字段留空时不会显示按钮。

## 论文与新闻

论文填写标题、作者、年份、类型、发表状态、期刊／会议和 DOI。PDF、摘要、BibTeX 可选填；前台支持搜索、按类型筛选、展开摘要和复制引用。

新闻填写标题、日期、分类、摘要和正文，开启发布后出现在 News 页，最新三条进入首页。日期代表显示日期；未来日期不会自动定时发布，请在发布当天开启发布。

原站的 8 条示例或未核实新闻已保留为草稿，发布前请核实事实与链接。部分作品有“编辑备忘”提示，搜索“原站没有”可找到需要补充说明的项目。

## 草稿、发布和恢复

“发布到网站”关闭时，作品、论文或动态不出现在网站。项目和动态的详情页也不生成。后台富文本可查看正文排版，完整网页布局在发布构建后打开对应网页查看；使用电脑和手机检查图片、文字与下载链接。

**仓库是公开的，草稿文件在 GitHub 上仍可查看，请勿存放敏感信息。**

每次点击保存会产生 GitHub 提交，GitHub Pages 随后自动构建。通常几分钟后刷新网站即可看到变化。如果没有更新，确认分支是 main、发布已开启，然后查看 [构建记录](https://github.com/doubleteng/tengteng/actions)。

关闭发布即可撤下内容，无需删除。修改错误可在 GitHub 文件的 **History** 中找到旧版本并恢复；全站改动也可通过提交历史回退。

## 内容与文件对照

| 后台菜单 | 仓库文件 | 前台位置 |
| --- | --- | --- |
| 作品管理 | `_projects/*.md` | 首页精选、Research、Teaching、Design、All Work、详情页 |
| 论文与出版物 | `_publications/*.md` | Publications |
| 新闻与动态 | `_updates/*.md` | News、首页最新动态 |
| 个人资料与简历 | `_data/profile.yml` | About、首页身份、Contact、页脚邮箱 |
| 教学介绍与课程 | `_data/teaching.yml` | Teaching |
| 艺术作品 | `_data/fine_art.yml` | Fine Art |
| 网站文字与设置 | `_data/site.yml` | 各页介绍、联系表单开关、导航、页脚 |
| 图片素材 | `assets/media/` | 图片字段引用的位置 |
| PDF 与文件 | `assets/documents/` | 简历、论文和下载文件 |

日常使用无需修改 HTML、JavaScript、Jekyll 配置或 `.pages.yml`。

## 上传视频

在作品的「图文内容区块」中添加「视频」，点击「上传或选择视频」选择 MP4 或 WebM 文件，也可以填写 YouTube 或 Vimeo 链接。选择了文件时优先播放该文件。「视频封面图」留空时使用作品封面。保存作品后网站自动更新。建议先压缩视频，缩短上传和播放等待时间。

## 研究方法与课程页面

在 **研究方向** 中修改研究方向的标题、问题和说明。项目中的“研究方向”可填写 `material-computation`、`interfaces-and-tools`、`spatial-history`，并可同时填写多个方向。同一项目可以从 Research 与 Teaching 或 Design 进入，无须复制项目记录。

项目表单新增卡片短标题、研究或教学问题、方法步骤、验证依据及适用范围、我的具体贡献、主要链接和关联项目网址。方法步骤显示在正文上方，原有图片、图集和视频继续由内容块管理。

**教学与课程** 中可编辑精选教学项目、当前课程和拟开设课程。未来课程应继续明确标为 Proposed teaching。首页和 About 的 CV 下载链接由个人简介中的 CV 文件字段管理。
