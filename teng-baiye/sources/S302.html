文献说明Document note

这一位置可用于追查1931年第一号年报，但目录没有逐件列明具体期号，也没有写出滕白也姓名。不能据此认定卷宗必含其材料。This is a possible location for the cited 1931 report. The finding aid does not enumerate individual issues or name Teng, so the presence of that report or Teng-related content remains unconfirmed.
